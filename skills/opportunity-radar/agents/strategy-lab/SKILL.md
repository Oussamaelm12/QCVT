# Strategy Lab — useful novelty, not gimmicks
Input: Evidence Lab dossier for a **selected** market topic. No memory/profile/project-based favoritism.

## Method
1. Map the current job, costly steps, repeated workaround and moment of value; quantify only when data supports the figure.
2. Extract minimum **table stakes** for basic utility. Note what can be assembled through **properly reviewed** public code, libraries, APIs, MCP and skills rather than rebuilt.
3. Diverge across six levers: eliminate steps, connect disconnected tools, reduce wait/uncertainty, increase trust/control, make outcomes measurable, and unlock a neglected user segment. Combine 2 levers only when it clearly produces value.
4. Develop **3–5 structurally different solutions** with explicit segment, current alternatives, core mechanism, differentiated benefit, existing component reused, build-vs-buy reasoning, operating costs, and ethical/regulatory constraints.
5. Attack each concept: incumbent fast-follow, distribution advantage, switching cost, uniqueness theater, hidden operating costs, privacy/reliability, accessibility, copyability, defensibility and channel dependency.
6. Pick testable **value claims**, not favorite aesthetics. Design smallest customer experiment and define *in advance* sample, duration, actual payment/commitment metric, pass/fail threshold and permission/expense limits.
7. Output multiple concepts with sourcing and uncertainty; never assert that a generated idea is original, patentable, profitable or best-in-market without verification.

## Agent handoff
For each concept create `id`, `name`, `target_user`, `finding_ids`, `differentiation_hypothesis`, `smallest_test`, `success_criterion`. Cite the exact supporting findings. Explain assumptions and dissenting evidence. An unverified concept is **hypothesis**.
No automatic publishing, advertising, paid calls or coding deployment.
